EVT-MARL: Risk-Averse Multi-Agent Reinforcement Learning via Extreme Value TheoryModeling Firm Decision-Making under Heavy-Tailed Political-Economic UncertaintyWorking Paper — Ehsan Karimi (2026)📌 OverviewThis repository provides an Extreme Value Theory (EVT) informed Multi-Agent Reinforcement Learning (MARL) framework. It is designed to model firm decision-making under severe, heavy-tailed political-economic uncertainty (e.g., sanctions-driven exchange rate shocks).Standard MARL often assumes well-behaved environmental stochasticity, leaving multi-agent networks vulnerable to catastrophic failure. This framework extends the single-agent POTPG approach (Davar, Godin & Garrido, 2024) to a multi-agent, networked setting. Each agent's (firm's) reward function is penalized by two Conditional Value-at-Risk (CVaR) terms:Individual Tail Risk: Estimated from real historical exchange rate data using a Generalized Pareto Distribution (GPD).Systemic/Network Risk: Capturing the correlated nature of macro-shocks that impact the entire network simultaneously.🔑 Key FindingThe EVT-aware framework produces substantially lower-variance and more predictable fragility behavior under severe shocks compared to a risk-neutral baseline (fragility SD: 0.07 vs 1.60 across seeds). This advantage is highly concentrated during sudden, discrete extreme events rather than gradual trends—a boundary condition identified via crossover analysis on empirical sanctions data (2018–2025).📊 Empirical Data & Tail RiskThe simulation is grounded in empirical financial and political data:DatasetCoverageDescriptionTail BehaviorUSD/IRR Free-Market Rate2012–2026 (5,052 obs.)Real exchange rate shocksFat-tailed (Excess kurtosis: 17.4, GPD ξ ≈ +0.11)Sanctions Events2012–2025 (21 events)OFAC, Iran Primer, EU ConsiliumDiscrete extreme political shocksTEDPIX (Tehran Stock Exchange)2008–2026 (4,260 obs.)Market response indexBounded tail (ξ ≈ −0.18) due to regulatory daily price bands🧠 Framework & MathematicsReward FunctionStandard RL maximizes expected cumulative reward.
